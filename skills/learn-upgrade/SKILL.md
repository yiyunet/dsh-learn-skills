# learn-upgrade：框架与大脑升级

## 目标
让框架索引与 AGENTS.md（大脑）跟节点变化保持同步。

## 步骤
1. 读 `knowledge/framework.md`，核对节点目录与 nodes/ 实际文件一致；更新版本 / 日期 / 状态。
2. 审视各节点「核心要点」，判断哪些已稳定、不会随工具版本过时。
3. 把稳定规则提炼进工作区 `AGENTS.md` 的「核心心智模型」段（只加不变的原则）。
4. 同步更新 framework.md 的「心智模型」段（两处镜像）。
5. 可复用操作流程交给 learn-skillify，不塞进 AGENTS.md。

## 铁律
- AGENTS.md 保持精炼：只装原则，细节一律留在节点。
- 改 AGENTS.md 前先确认是「稳定」而非「当前版本细节」。
